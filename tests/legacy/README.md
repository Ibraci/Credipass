# Tests historiques archivés

Ces tests vérifient des contrats de releases anciennes (R6, R7, R9, R10, R16) qui ont été remplacés par les contrats R17/R18/R18.1. Ils sont conservés pour traçabilité mais ne font plus partie de la suite active de release. Ils ne doivent pas être interprétés comme des critères de validation R18.1.

R18.2 et R18.3 production-green ont été déplacés ici en R18.4 : leurs assertions de cache/version sont volontairement figées sur des releases remplacées. Les contrats fonctionnels utiles sont repris par les tests R18.4.
