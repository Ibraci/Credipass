# CREDIPASS R18.5 — Consolidation des rôles

Décision métier : réduction du référentiel à 10 rôles principaux.

1. Gérant / Chef d’agence (`gerant`)
2. Agent de crédit (`agent.credit`)
3. Analyste / Responsable crédit (`analyste.credit`)
4. Conformité / Contrôle / Risques (`conformite`)
5. Comité de crédit (`comite.credit`)
6. Caisse / Comptabilité (`caisse`)
7. Suivi / Recouvrement (`suivi.credit`)
8. Direction (`direction`)
9. Auditeur (`auditeur`)
10. Administrateur Système (`admin.systeme`)

L’Agent ne crée pas les membres. Le Gérant crée/affecte les membres. L’Administrateur Système regroupe administration fonctionnelle, utilisateurs, technique et infrastructure, sans pouvoir métier de décision crédit.
