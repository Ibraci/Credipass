# Données synthétiques CREDIPASS

Ce dossier contient exclusivement des jeux de données fictifs utilisés pour les tests automatisés, la présentation et la validation fonctionnelle.

- Aucune donnée client réelle ne doit être placée ici.
- Ces données ne constituent pas des paramètres réglementaires ou institutionnels de production.
- Les valeurs, institutions, identifiants et scénarios sont synthétiques.
- Les moteurs de production restent dans `src/engines`, les politiques dans `src/config` et les données synthétiques dans `src/fixtures`.
